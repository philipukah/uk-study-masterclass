# UK Study Success Masterclass Landing Page

Static landing page for the Friday and Saturday UK Study Success Masterclass.

## Deployment

- Entry file: `index.html`
- Build command: none
- Hostinger branch: `main`
- Hostinger install path: `public_html/uk-study-masterclass`

## Before paid traffic

The current registration form is preview-only. Connect the `leadForm` submit handler in `index.html` to the approved CRM or webhook before running ads.

Add Meta Pixel and TikTok Pixel configuration using the organization’s approved IDs. Trigger lead/conversion events only after the CRM confirms a successful submission.
